# Precharge unit

This electrical component controls the main relay, in order to avoid in-rush currents.

High voltages and loads with large capacitors need to be switched on in a controlled way : that is the role of the precharge unit. When the key is turned on, it lets the voltage ramp up, over a few seconds, in a controlled way before activating the main relay.

# Main relay

The main relay is a Tyco/Electronics kilovac EV relay 48V / 500A, it is controlled by the precharge unit.

# Fuses and main switch

Right next to the battery is a high capacity main switch 600A.
A 400A ANL fuse is placed on a Victron Energy ANL fuse holder.
Finally, the VESC is fitted with a 350A slow automotive fuse.
